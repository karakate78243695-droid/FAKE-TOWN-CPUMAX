วิธีเปิดเว็บ FAKE TOWN

1. ดับเบิลคลิก เปิดเว็บ.cmd และเปิด http://localhost:4173 ในเบราว์เซอร์
2. กรอก Discord Client Secret และ Bot Token ในไฟล์ .dev.vars แล้วเปิดเว็บใหม่
3. ตั้ง Redirect URI ของ Discord เป็น http://localhost:4173/auth/discord/callback
4. ยศ DEV / ADMIN / SUPPORT ตั้งไว้ตาม ID ที่ให้แล้ว
5. การตรวจสลิปต้องมี EASYSLIP_API_KEY และยืนยันบัญชีรับเงินก่อนตั้ง EASYSLIP_ACCOUNT_REGISTERED=1

ต้องใช้ Node.js รุ่นที่รองรับ node:sqlite เช่น Node.js 22.13 ขึ้นไป
ฐานข้อมูลในเครื่องจะสร้างใน .sites-runtime เมื่อเปิดเว็บ
ไฟล์นี้ไม่รวม Token หรือฐานข้อมูลของผู้เล่น
ร้านค้าเริ่มว่าง ให้ทีมงานเพิ่มสินค้าและราคาจริงในหน้าแอดมิน
การส่งสินค้าเข้าเกมเป็นการส่งโดยทีมงาน ซองทรูมันนี่ยังไม่ได้เชื่อมต่อ
ดูรายละเอียดเพิ่มเติมใน README.md
