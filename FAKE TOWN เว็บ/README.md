# FAKE TOWN

เว็บไซต์ชุมชน FiveM พร้อมล็อกอิน Discord ร้านค้า VIP / ไอเทม / สกิน / รถ / แพ็กเกจ เครดิต ประวัติคำสั่งซื้อ และหน้าแอดมิน

## สิทธิ์ทีมงาน

ตรวจยศจาก Discord ฝั่งเซิร์ฟเวอร์ทุกครั้งที่เข้าหน้าแอดมินหรือส่งคำสั่งแก้ไข:

- DEV: `1524378458313064560`
- ADMIN: `1524378460364079227`
- SUPPORT: `1524378456589336756` อ่านคำสั่งซื้อและรายการเติมเงินได้

DEV และ ADMIN จัดการสินค้าและยืนยันการส่งสินค้าในเกมได้ ส่วน DEV เห็นสถานะการเชื่อมต่อด้วย เว็บยังไม่ได้ส่งไอเทมหรือรถเข้าเกมอัตโนมัติ ทีมงานต้องส่งของให้ผู้เล่นแล้วกดยืนยันสถานะ

## ค่าที่ต้องตั้งก่อนเปิดบริการจริง

ตั้งค่าลับผ่านระบบ Environment Variables ของ Sites ห้ามใส่คีย์ในหน้าเว็บหรือ commit:

1. `DISCORD_CLIENT_ID`: `1555828402299211776`
2. `DISCORD_CLIENT_SECRET`: Client Secret จาก Discord Developer Portal > OAuth2
3. `DISCORD_BOT_TOKEN`: token ของบอทที่อยู่ใน Discord ของเมือง
4. `DISCORD_GUILD_ID`: ID ของ Discord เซิร์ฟเวอร์ FAKE TOWN
5. `SITE_ORIGIN`: โดเมนเว็บจริง
6. `EASYSLIP_API_KEY`: API key จาก EasySlip
7. `EASYSLIP_ACCOUNT_REGISTERED`: ตั้งค่าเป็น 1 หลังเพิ่มและยืนยันบัญชีรับเงินกสิกรใน EasySlip

เพิ่ม Redirect URI ใน Discord Developer Portal:

`https://fake-town-community.classycivet.chatgpt.site/auth/discord/callback`

เลขบัญชีรับเงินที่ระบุ: กสิกรไทย `214-8-04701-7` สิปปกร ทวีเพชร

ระบบตรวจยอด บัญชีผู้รับ และสลิปซ้ำก่อนเพิ่มเครดิต โดยเลขอ้างอิงโอนเงินต้องไม่ซ้ำในฐานข้อมูล ข้อมูลเครดิตและราคาคำนวณเป็นหน่วยสตางค์ การหักเครดิตและสร้างคำสั่งซื้อเป็นรายการในธุรกรรมเดียวกัน

ไม่เปิดรับเงินจริงก่อนตั้ง API ตรวจสลิปและบัญชีผู้รับครบ ซองทรูมันนี่ยังไม่เปิดรับ เพราะยังไม่มีการเชื่อมต่อผู้ให้บริการรับซองที่ตรวจสอบยอดได้

เว็บที่สร้างผ่าน Sites เริ่มแบบส่วนตัว ให้ตั้งค่าการแชร์เป็นสาธารณะหลังตรวจฟังก์ชันล็อกอิน ชำระเงิน และสิทธิ์ทีมงานครบ หากยังเป็นส่วนตัว ลูกค้าทั่วไปเข้าไม่ได้

## พัฒนา

`npm install`, `npm run db:generate`, `npm run build`, `npm run dev`

ตัวอย่างใช้ SQLite ในเครื่องจริงและ schema เดียวกับ production โดยไม่มีบัญชีหรือตัวเลขเครดิตจำลอง หลังสร้าง migration แล้วให้ commit โฟลเดอร์ `drizzle` ไปด้วย
